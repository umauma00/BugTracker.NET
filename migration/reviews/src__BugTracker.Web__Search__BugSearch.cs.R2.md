Inventory row L55 says `"btnet"` (followed here), but `_client.DefaultIndex()` and `null` (the runtime falls back to the default index, `ElasticClient.java:88`) are equally plausible and give the same URL today. Either way it should be pinned in the rule, not only in the inventory. Evidence: `BugSearch.cs:55`, `BugSearchFactory.cs:19-22`, `ElasticClient.java:78,87-88`.

- **G4 — Names for locals the translation introduces.** The NEST lambda-to-JSON rewrite creates new locals (`queryString`, `query`, `highlight_`, `fields`, `searchBody`, `body`).
